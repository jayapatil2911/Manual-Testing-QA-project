# 🧪 SauceDemo – Manual Testing QA Project

## 📌 Project Overview

**SauceDemo** is a web-based e-commerce application used for practicing and demonstrating software testing activities.

This repository contains end-to-end **Manual Testing QA artifacts** created as part of my Software Testing portfolio project.

The objective of this project is to demonstrate real-world QA practices including **test planning, test scenario design, test case creation, test data preparation, test execution, defect reporting, requirement traceability, and test summary reporting**.

## 📊 Project Goal

To build a complete **Manual Testing QA portfolio project** using the SauceDemo web application and demonstrate industry-standard software testing practices.

The project covers the complete testing lifecycle, including:

- Test Planning
- Test Strategy
- Test Scenario Design
- Test Case Design
- Test Data Preparation
- Requirement Traceability Matrix (RTM)
- Test Execution
- Defect Identification and Reporting
- Retesting
- Regression Testing
- Test Execution Summary

The project includes **87 test cases** covering Login, Products, Product Sorting, Cart, Checkout, Purchase, Logout, UI validation, and user-specific scenarios.

The project is designed to demonstrate practical QA skills that can be showcased during **Software Testing / QA interviews and job applications**.
